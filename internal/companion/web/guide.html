Как подключить Jardulik Companion

Для первого подключения открой Telegram Web на компьютере. После подключения пользоваться ботом можно и с телефона.

Подключай только свой аккаунт Jardulik. Ссылка запуска даёт временный доступ к аккаунту. Отправляй её только командой /connect в личном чате помощника.

  1. Открой Jardulik

    Зайди в Telegram Web с того же аккаунта, с которого будешь писать помощнику. Открой @jardulik_bot и запусти мини-приложение.

  2. Скопируй ссылку запуска

    Через меню браузера открой Инструменты разработчика. Выполни поиск по mini.jardulik.app во вкладке Элементы (Elements) и найди iframe с этим адресом.

    Скопируй только значение src целиком, без наружных кавычек. Оно должно начинаться с https://mini.jardulik.app/ и содержать tgWebAppData после #. Для этого шага достаточно поиска во вкладке Элементы.

  3. Подключи помощника

    Открой бота и нажми Запустить. Прочитай политику данных, затем отправь команду и адрес одним сообщением.

    /connect <полный URL запуска Jardulik>

    Дождись подтверждения и отправь /next, чтобы открыть первую анкету. Бот попробует удалить сообщение со ссылкой. Если оно осталось в чате, удали его вручную.

Как пользоваться

  • /status показывает состояние подключения.
  • /menu открывает меню. Автолайки включаются отдельно в настройках.
  • /pause останавливает фоновые действия. /disconnect отключает сессию и сохраняет архив.
  • /delete запрашивает удаление личных данных из рабочей базы с подтверждением.

Если подключение не получилось

Причины ошибок и что делать
  • Ссылка устарела. Закрой мини-приложение, снова запусти его из @jardulik_bot и скопируй свежий адрес.
  • Ссылка принадлежит другому аккаунту. Проверь, что Telegram Web и чат с помощником открыты под одним Telegram-аккаунтом.
  • В ссылке нет tgWebAppData или подпись не подтверждена. Проверь, что открыт официальный Jardulik, и заново скопируй весь src без ручных изменений. Если поля в адресе по-прежнему нет, используй официальный Jardulik и обратись за помощью.
  • Jardulik отклонил вход или запросил дополнительную проверку. Открой официальное приложение и следуй его подсказкам.

Помощник проверяет адрес, подпись Telegram, свежесть ссылки и совпадение аккаунта. Как Telegram подписывает данные запуска ↗

/help показывает список команд. Чтобы написать оператору, отправь /support и описание проблемы одним сообщением, без ссылки запуска и токенов.
