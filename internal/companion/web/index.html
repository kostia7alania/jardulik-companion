📲 Готовый сервис

Начни в личном чате с ботом.

Открыть инструкцию ↗

  1. Запусти бота

    Открой Jardulik Companion в Telegram и нажми «Старт».

  2. Подключи свой аккаунт

    Нажми «Подключить» в меню и следуй подсказкам бота.

  3. Открой меню

    Сохраняй анкеты и настрой автоматизацию. Автолайки включаются отдельно.

🖥️ Свой сервер

Склонируй репозиторий. Для работы с ботом задай свой токен и ключи в файле .env.local.

Готовые сборки ↗ Инструкция по установке ↗

🎮 Локальное демо

docker compose up --build

📲 Свой бот

docker compose --profile live up --build -d

Демо откроется на localhost:8787.

💬 Частые вопросы

Нужны аккаунт и Premium?

Для готового сервиса нужна своя анкета в Жардулике. Companion работает с возможностями и лимитами твоего тарифа. Подписка оформляется в самом Жардулике.

Как подключиться с телефона?

Для первого подключения удобнее компьютер с Telegram Web. Дальше ботом можно пользоваться с телефона. Шаги есть в инструкции.

Что попадает в историю?

У каждого подключённого аккаунта своя очередь и избранное. Бот сохраняет доступные тебе анкеты независимо от лайков. Когда описание или фото меняются, в истории появляется новая версия. Telegram может сжимать фото в альбоме. ZIP в архиве сохраняет файлы в том виде, в каком их отдал Jardulik.

Когда бот отправляет автолайки?

После отдельного включения в настройках и в пределах выбранных фильтров. Jardulik может менять условия доступа и лимиты.

Как сделать паузу или удалить данные?

/pause останавливает фоновые действия. /disconnect отключает аккаунт и сохраняет архив. /delete запрашивает удаление данных из рабочей базы. Подробнее в политике конфиденциальности.
